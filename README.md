# Bhatkal Halls API

Backend REST API for **Bhatkal Halls** - A platform to discover, compare and book wedding halls, auditoriums and banquet halls in Bhatkal.

Built with Node.js, Express.js & MongoDB.

## 🚀 Features
- User Authentication (Register, Login, JWT + Cookies, Forgot/Reset Password)
- Role-based Access (User / Admin / Hall Owner)
- Hall Management (CRUD, Images, Amenities, Pricing)
- Availability & Booking System
- Secure Payments
- Admin Dashboard APIs
- Rate Limiting & Data Encryption

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB + Mongoose
- **Auth:** JWT, bcrypt, Crypto
- **Security:** Helmet, xss-clean, express-rate-limit, cookie-parser
